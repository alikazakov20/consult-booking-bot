# consult-booking-bot

Telegram-бот для записи на консультации. Клиент получает персональную ссылку → переходит по ней в бота →
прямо в чате (без сайтов и веб-страниц) выбирает свободную дату и время кнопками → бронь создаётся
автоматически, вам приходит уведомление. Всё происходит внутри Telegram — никакого стороннего хостинга
для интерфейса не требуется.

## Как это работает

1. Вы выдаёте клиенту ссылку командой `/newlink` (например, после оплаты консультации) — бот присылает
   вам `https://t.me/<ваш_бот>?start=<токен>`.
2. Клиент переходит по ссылке → видит кнопки с ближайшими рабочими днями → выбирает день → видит кнопки
   со свободным временем → выбирает время → бронь создаётся сразу.
3. Если это время только что заняли (два человека нажали одновременно) — бот не даст забронировать
   дважды и предложит выбрать другое: это проверено вживую двумя параллельными запросами на один слот.
4. Вам приходит сообщение: «📥 Новая запись: Имя — 8 сентября в 14:00».
5. Ссылка одноразовая — после брони по ней уже нельзя записаться повторно.

Больше в боте ничего нет: ни отмены, ни напоминаний, ни настройки часов из чата — по вашей просьбе
оставлена только эта цепочка.

## Расписание — зафиксировано в коде

Рабочие дни, часы и длительность консультации не настраиваются через бота — они заданы константами
в `server/src/schedule.ts`:

```ts
export const WORK_WEEKDAYS = [1, 2, 3, 4, 5]; // Пн–Пт
export const WORK_START_MIN = 9 * 60;          // 09:00
export const WORK_END_MIN = 18 * 60;           // 18:00
export const SLOT_MINUTES = 60;                // длительность одной консультации
export const BOOKING_HORIZON_DAYS = 60;        // на сколько дней вперёд можно записаться
```

Если понадобится изменить часы работы или длительность — поправьте эти значения и перезапустите бота.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
2. Узнайте свой numeric Telegram ID через [@userinfobot](https://t.me/userinfobot) — это `ADMIN_TELEGRAM_ID`.
   Только вы сможете выдавать ссылки командой `/newlink`.
3. Скопируйте `server/.env.example` → `server/.env`, впишите оба значения.

## Запуск

Бот — это один обычный Node-процесс, отдельный хостинг ему не нужен: работает там, где вы его запустите
(на своём компьютере, на сервере, где угодно), пока этот процесс работает — бот отвечает.

```bash
npm install
npm run prisma:migrate --workspace server   # создаёт локальный файл SQLite и таблицы

npm run dev --workspace server               # запуск с автоперезапуском при правках кода
```

Для постоянной работы (продакшн-сборка):

```bash
npm run build   # компилирует server/src → server/dist
npm start       # node server/dist/index.js
```

Чтобы бот продолжал отвечать, пока вы не пользуетесь компьютером — оставьте этот процесс работать
(например, через `pm2` или `nohup ... &`), либо когда-нибудь перенесите его на сервер: это тот же самый
`npm run build && npm start`, никаких дополнительных настроек не потребуется.

## Данные

Все ссылки и записи хранятся в одном файле `server/prisma/dev.db` (SQLite) — ничего внешнего заводить
не нужно. Файл в `.gitignore`, при переносе бота на другую машину скопируйте его вместе с проектом,
если хотите сохранить историю записей.
